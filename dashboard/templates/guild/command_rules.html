Permission rules decide who may run a command, custom commands reply with text you write, and aliases are shortcuts for existing commands.

  • The most specific rule wins: member, then role, then channel, then category, then the whole server. At the same level a deny beats an allow
  • A rule's subject is a command, a whole category (cog:Name) or * for everything
  • Commands in the Config category can never be ruled, so nobody can lock themselves out
